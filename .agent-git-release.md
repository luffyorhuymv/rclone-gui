# Agent-only git/release note

File an nay danh cho AI/IDE agent doc truoc khi lam viec voi GitHub, push hoac release.

```text

```

## Nguyen tac commit

- Luon kiem tra truoc:

```powershell
git status --short --branch
git diff --stat
```

- Khong revert thay doi khong phai cua minh.
- Khong dung:

```powershell
git reset --hard
git checkout -- .
git clean -fd
```

- Neu build app Windows, thuong commit ca:

```text
RcloneDriveManager/Program.cs
RcloneDrive.exe
```

- Khong commit:

```text
rclone.exe
*_RcloneDrive.exe
cache/
temp/
```

## Nguyen tac push

- Push len:

```powershell
git push origin main
```

- Chi push khi user yeu cau hoac task ro rang can dong bo GitHub/release.
- Neu co file chua ro nguon goc, hoi lai hoac bo qua, khong tu xoa.

## Nguyen tac release

- Dung semver tag:

```text
v1.0.13
v1.0.14
v1.0.15
```

- Khong dung tag ngay.
- Khong xoa release cu neu user khong noi ro.
- Moi release can attach:

```text
RcloneDrive.exe
```

- Lenh tao release mau:

```powershell
$repo = 'luffyorhuymv/rclone-gui'
$tag = 'v1.0.57'
$notes = @'
## v1.0.13

- Ghi tom tat thay doi o day.
'@
gh release create $tag .\RcloneDrive.exe --repo $repo --target main --title $tag --notes $notes
```

- Kiem tra release:

```powershell
gh release view v1.0.13 --repo luffyorhuymv/rclone-gui --json tagName,url,targetCommitish,assets
```
